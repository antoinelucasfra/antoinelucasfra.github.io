# Contributing

## Resources catalog

The resources catalog is its own project: [antoinelucasfra/resources-catalog](https://github.com/antoinelucasfra/resources-catalog), live at [antoinelucasfra.github.io/resources-catalog](https://antoinelucasfra.github.io/resources-catalog/).

To suggest a resource, fork that repo, edit `resources.txt`, and open a pull request there. The [field reference and PR guide](https://github.com/antoinelucasfra/resources-catalog/blob/main/CONTRIBUTING.md) live in that repo.

## Blog posts

1. **Fork** the repository on GitHub
2. **Add a post** as `posts/<slug>/index.qmd` with frontmatter for the listing:

   ```yaml
   ---
   title: "Post title"
   description: "One or two sentences shown in the listing and OG tags."
   date: "YYYY-MM-DD"
   categories: [R, Shiny]
   ---
   ```

3. **Open a pull request** against `prod` with a short description of the post

Rules:

- Do not hand-edit files in `docs/`. They are generated by `quarto render` and re-rendered by CI; commit `docs/` only as the output of a render run
- Never hardcode credentials, tokens, or email addresses in source files
- Never commit `.env` files or any file containing secrets
- Never run `git add .` without reviewing staged changes first
